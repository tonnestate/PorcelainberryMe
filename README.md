# PorcelainberryMe

Lightweight, provider-neutral communication fabric for FruitStack.

## Scope

Bidirectional messages and future calls across email, WhatsApp, SMS and phone, with a unified communication contract. PorcelainberryMe owns transport and delivery state, **not** model selection, cognition, CRM master data, voice identity or business decisions.

- Existing Aurora, AnanasMe, TonnEstate and FruitStack services remain authoritative.
- No new local speech model is installed or downloaded.
- No production deployment or live outbound messages are performed by source changes.
- The previously successful Python voice implementation must be identified by **source file and observed audio** before it is connected. Qwen3-TTS is not a production baseline.
- The first implementation is developed on a feature branch with offline tests before any merge.

Implementation status: **scaffold only on main**. See the feature branch and pull requests for working milestones.
